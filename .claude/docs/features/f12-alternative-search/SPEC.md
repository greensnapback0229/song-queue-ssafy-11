# F12: YouTube 대체 검색 결과 (가사 MR)

## Purpose

기본 검색(금영노래방)에서 마음에 드는 영상이 없을 경우, "다른 검색결과" 버튼을 눌러 `가사 MR` 키워드로 재검색한 결과를 볼 수 있도록 한다. TJ노래방 영상은 임베딩 불가이므로 결과에서 자동 제외한다.

## Flow Summary

1. 관리자가 노래 제목 입력 → "YouTube 검색" 클릭
2. 기본 검색: `{제목} 금영노래방` 결과 표시
3. 마음에 안 들면 "다른 검색결과" 버튼 클릭
4. 대체 검색: `{제목} 가사 MR` 결과 표시 (TJ노래방 제외)
5. 다시 "금영노래방 검색결과" 버튼으로 토글 가능

## 범위 정의

### 포함 (In Scope)
- YouTube 검색 API에 `keyword` 파라미터 추가 (`금영노래방` / `가사 MR`)
- 서버에서 `[TJ노래방]` 포함 결과 필터링
- 필터링으로 빠진 만큼 추가 결과 요청 (항상 5개 유지)
- DequeueModal에 "다른 검색결과" / "금영노래방 검색결과" 토글 버튼

### 제외 (Out of Scope)
- 커스텀 키워드 입력
- 3개 이상의 검색 모드
- 검색 결과 캐싱

## 변경 파일

| 파일 | 작업 | 설명 |
|------|------|------|
| `src/app/api/youtube/search/route.ts` | 수정 | `keyword` 쿼리 파라미터 추가, TJ노래방 필터링 |
| `src/components/Queue/DequeueModal.tsx` | 수정 | "다른 검색결과" 토글 버튼 추가 |

## API 변경: `GET /api/youtube/search`

### 파라미터

| 파라미터 | 타입 | 기본값 | 설명 |
|----------|------|--------|------|
| `q` | string | (필수) | 검색어 |
| `keyword` | string | `금영노래방` | 검색 키워드 (`금영노래방` 또는 `가사 MR`) |

### 동작
- 검색어: `{q} {keyword}`
- `keyword=가사 MR`일 때: 결과에서 제목에 `[TJ노래방]` 또는 `TJ노래방` 포함된 항목 제외
- 필터링 후 5개 미만이면 `maxResults`를 늘려 재요청하여 5개 채움

### 응답 (변경 없음)
```json
{
  "results": [
    { "videoId": "...", "title": "...", "channelTitle": "...", "thumbnailUrl": "..." }
  ]
}
```

## Behavior Rules

### 1. DequeueModal UI
- 기본 검색 결과 아래에 "다른 검색결과" 버튼 표시
- 대체 검색 결과 표시 중이면 "금영노래방 검색결과" 버튼으로 변경
- 토글 시 기존 선택 해제
- 버튼 스타일: 텍스트 링크 형태 (예: 파란색 밑줄)

### 2. 검색 모드 전환
- "다른 검색결과" 클릭 → `keyword=가사 MR`로 API 호출
- "금영노래방 검색결과" 클릭 → `keyword=금영노래방`으로 API 호출
- 각 전환 시 새로 API 호출 (캐싱 없음)

### 3. TJ노래방 필터링 (서버)
- 제목에 `[TJ노래방]` 또는 `TJ노래방` 문자열 포함 시 제외
- 대소문자 무관 (TJ, tj, Tj 모두 매칭)
- `금영노래방` 키워드 검색 시에는 필터링 적용 안 함
- `가사 MR` 키워드 검색 시에만 필터링 적용

## Edge Cases

| 케이스 | 동작 |
|--------|------|
| 대체 검색 결과도 0개 | 빈 리스트 표시 |
| TJ 필터링 후 결과 0개 | 빈 리스트 표시 |
| 검색 중 모드 전환 | 이전 검색 취소, 새 검색 실행 |
| 영상 선택 후 모드 전환 | 선택 해제 |

## Error Handling

- 기존 YouTube 검색 에러 처리와 동일
- `keyword` 파라미터 누락 시 기본값 `금영노래방` 사용

## Test Strategy

### 수동 검증
1. 기본 검색 → 금영노래방 결과 확인
2. "다른 검색결과" 클릭 → 가사 MR 결과 확인, TJ노래방 영상 없음 확인
3. "금영노래방 검색결과" 클릭 → 다시 금영노래방 결과로 복귀
4. 대체 검색에서 영상 선택 → 미리보기 정상 동작
5. 모드 전환 시 이전 선택 해제 확인
